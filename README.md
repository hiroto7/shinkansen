# JRE POINT特典チケットのレート計算

JRE POINT特典チケットの交換ポイントを、同じ区間・設備を現金で利用する場合の所定額と比較するWebアプリです。

2026年3月14日以降の現行版と、2022年3月12日時点の参考版を切り替えられます。

普通車指定席では、指定席だけでなく自由席・立席の所定額とも比較できます。グリーン車とグランクラスでは、指定した設備・行程と同じ内容の所定額を比較します。

2026年版では、全線35%特別レートと、公式表の対象駅間に限った信州プレDCの交換レートも選択できます。

計算対象、比較方法、区間指定の制約は[設計方針](docs/design-principles.md)にまとめています。

## 開発

Node.js 24以降を使用します。

```sh
npm install
npm run dev
```

## 検証

```sh
npm run typecheck
npm test
npm run build
```

## 計算データの方針

- 運賃・料金は旅客営業規則とJR東日本の公式運賃表だけから実装します。
- 乗換案内サイトなどが表示する金額を、計算ロジックやデータとして取り込みません。
- `2022-03-12` と `2026-03-14` を別の年版として保持します。
- 「はやぶさ」「こまち」の利用区間と、各座席設備の利用区間は、それぞれ連続した1区間だけを扱います。

2026年版の一次資料は、[JR東日本の運賃改定案内](https://www.jreast.co.jp/2026unchin-kaitei/)、[旅客営業規則](https://www.jreast.co.jp/ryokaku/)、[えきねっとの商品ページ](https://www.eki-net.com/top/product/shinkansen/e-tokuten.html)です。
